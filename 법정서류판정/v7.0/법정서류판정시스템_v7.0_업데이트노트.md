# 법정서류 판정 시스템 v7.0 업데이트 노트

> **업데이트 일자:** 2025.01.27
> **법령 기준:** 2025.10.1 시행령
> **기반:** Safety Law OS v2.2

---

## 📋 버전 요약

| 항목 | v6.1 | v7.0 |
|------|------|------|
| 법령 기반 | 자체 정리 | Safety Law OS v2.2 완전 반영 |
| 특정시설 (HRP) | 6개 | **8개** (+종교시설, 지하도상가) |
| 가설구조물 | 4개 | **8개** (+브라켓비계, 동바리, 외부일체형, 복합형) |
| 폭발물 조건 | 단순 체크 | **세부조건** (20m 시설물 / 100m 가축) |
| SMP 창고 기준 | 없음 | **5,000㎡ 추가** |
| 서울시 조례 | 굴착 5m만 | **200㎡ 초과 추가** |
| 브랜드 컬러 | #1e3a5f | **#102b7d** (더베스트안전 CI 적용) |

## 🔧 주요 변경사항

### 1. 안전관리계획서 (CTP) 트리거 보완

**가설구조물 항목 확대 (4개 → 8개)**

| 기존 (v6.1) | 추가 (v7.0) |
|-------------|-------------|
| 비계 31m↑ | ✓ 유지 |
| 거푸집 5m↑ | ✓ 유지 |
| 흙막이 2m↑ | → 흙막이 **지보공** 2m↑로 명칭 명확화 |
| 터널 공사 | → 터널 **지보공**으로 분리 |
| - | **+ 브라켓 비계** (높이 무관, 전체 대상) |
| - | **+ 동바리 5m↑** |
| - | **+ 외부작업용 일체형 10m↑** |
| - | **+ 복합형 가설구조물** (현장제작) |

**폭발물 조건 세분화**
```
v6.1: 폭발물 사용 [체크] → 바로 CTP 대상

v7.0: 폭발물 사용 [체크]
      └─ 20m 내 시설물 있음 [체크]  ─┐
      └─ 100m 내 가축 사육 [체크]  ─┴─→ CTP 대상
```

**건설기계 분리**
- 기존: 항타·항발기만 있음
- 추가: **천공기 (10m 이상)** 별도 항목 분리

---

### 2. 소규모안전관리계획서 (SMP) 기준 보완

**추가된 기준**

| 시설 용도 | 기준 | 비고 |
|-----------|------|------|
| **창고** | 5,000㎡ 이상 | **신규 추가** |
| 공장 (산업단지 내) | 2,000㎡ 이상 | **별도 분리** (일반 공장 1,000㎡) |
| 서울시 | 연면적 200㎡ 초과 | **신규 추가** |

---

### 3. 유해위험방지계획서 (HRP) 특정시설 보완

**특정시설 목록 (6개 → 8개)**

| 기존 (v6.1) | v7.0 |
|-------------|------|
| 문화/집회시설 | ✓ |
| 판매시설 | ✓ |
| 운수시설 | ✓ |
| 종합병원 | ✓ |
| 관광숙박 | ✓ |
| 냉동냉장창고 | ✓ |
| - | **+ 종교시설** |
| - | **+ 지하도상가** |

> ⚠️ **제외 시설 주의**: 전시장, 동물원·식물원, 고속철도 역사, 집배송시설은 제외

---

### 4. UI/UX 개선

**브랜드 컬러 적용**
```css
/* v6.1 */
--navy: #1e3a5f;

/* v7.0 - 더베스트안전 CI 적용 */
--brand-primary: #102b7d;
--brand-secondary: #162759;
--brand-dark: #060f2c;
```

**폰트 변경**
- 기존: Noto Sans KR
- 변경: **Pretendard** (우선), Noto Sans KR (폴백)

**새로운 기능**
1. **판정 근거 표시**: 결과 화면에서 어떤 트리거에 의해 판정되었는지 명시
2. **통합 작성 안내**: CTP + HRP 동시 대상일 때 통합 작성 가능 안내
3. **인쇄 최적화**: `@media print` 스타일 추가
