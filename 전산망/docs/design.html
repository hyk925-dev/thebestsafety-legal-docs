1. 시스템 개요

건설현장 안전관리 컨설팅 업무를 위한 통합 전산 시스템입니다. 고객사/현장 관리, 월간 안전평가, 법정서류 판정, 알림 발송 등 핵심 업무를 디지털화합니다.

주요 사용자

역할 권한 설명
admin 전체 시스템 관리자, 모든 기능 접근
user 업무 더베스트안전 직원, 고객사/현장 관리
client 제한 고객사 담당자, 자사 데이터만 조회

2. 기술 스택

프론트엔드

5. 주요 기능

5대 영역 월간평가

안전보건 조직, 근로자 참여, 위험성 평가, 안전보건 교육, 비상 대응 체계 - 영역별 시행률 평가 및 등급 산정

법정서류 판정

공사 조건(금액, 층수, 높이, 면적 등)에 따라 필수 법정서류 자동 판정

알림 시스템

마감일 기준 D-3, D-1, 당일 알림. 이메일/SMS 발송. 템플릿 변수 치환 지원

SH평가

안전보건 경영시스템 인증 평가. 4대 영역 + 가점, 등급 산정 (S~D)

Excel 내보내기

평가, 현장, 고객사 데이터를 Excel 파일로 내보내기

대시보드

영역별 평균, 월별 추세 차트, 마감 임박 알림, 최근 평가 현황

평가 등급 기준

등급시행률색상
우수80% 이상녹색
양호60% 이상파랑
보통40% 이상노랑
미흡40% 미만빨강

초기 설정

# 1. 마이그레이션 실행
curl -X POST https://api-production-0ee5.up.railway.app/migrate \
  -H "Content-Type: application/json" \
  -d '{"secret":"tbsafe-init-2026"}'

# 2. 관리자 계정 생성 (최초 1회)
curl -X POST https://api-production-0ee5.up.railway.app/api/auth/init-admin \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@example.com","password":"your-password","name":"관리자"}'
