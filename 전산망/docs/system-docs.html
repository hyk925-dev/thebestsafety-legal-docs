시스템 개요

TBSafe란?

건설현장 안전관리 컨설팅 업무를 위한 통합 전산 시스템입니다. 고객사/현장 관리, 월간 안전평가, 법정서류 판정, 마감 알림 등 핵심 업무를 디지털화합니다.

핵심 기능

5대 영역 월간평가

안전보건 조직, 근로자 참여, 위험성 평가, 안전보건 교육, 비상 대응 체계 - 영역별 시행률 평가

법정서류 자동 판정

공사 조건(금액, 층수, 높이, 면적)에 따라 필수 법정서류 자동 산출

마감 알림 시스템

D-3, D-1, 당일 알림. 이메일/SMS 발송. 커스텀 템플릿 지원

SH평가 관리

안전보건 경영시스템 인증 평가. 4대 영역 점수 및 등급 산정

사용자 역할

역할 권한 대상
admin 전체 관리 (사용자, 설정, 일괄발송) 시스템 관리자
user 업무 기능 (고객사, 현장, 평가, 알림) 더베스트안전 직원
client 조회 전용 (자사 데이터만) 고객사 담당자

빠른 시작 가이드

1. 시스템 접속

웹 주소: Vercel 배포 URL 또는 로컬 개발 서버

API 주소: https://api-production-0ee5.up.railway.app

2. 초기 설정 (최초 1회)

# 1. 데이터베이스 마이그레이션
curl -X POST https://api-production-0ee5.up.railway.app/migrate \
  -H "Content-Type: application/json" \
  -d '{"secret":"tbsafe-init-2026"}'

# 2. 관리자 계정 생성
curl -X POST https://api-production-0ee5.up.railway.app/api/auth/init-admin \
  -H "Content-Type: application/json" \
  -d '{"email":"your@email.com","password":"your-password","name":"관리자"}'

3. 로그인

  1. 웹사이트 접속
  2. 이메일/비밀번호 입력
  3. 대시보드 진입

4. 기본 워크플로우

① 고객사 등록 → ② 현장 등록 → ③ 월간평가 입력 → ④ 알림 설정

평가 입력 방법

  1. 월간평가 메뉴 → "+ 새 평가"
  2. 현장 선택, 평가월 선택

  4. TBM 데이터, 비고 입력 (선택)
  5. 저장

엔티티 시스템

TBSafe 설계 엔티티란?

복잡한 설계 결정에 다양한 관점을 반영하기 위한 AI 페르소나 시스템입니다. 각 엔티티는 특정 전문 영역을 담당하며, 설계 회의를 통해 의견을 조율합니다.

필수 요구사항:

Architect
시스템 설계 전문가
구조적으로 좋은 방향입니다.

제안 스키마: 
legal_triggers (
  id SERIAL PRIMARY KEY,
  document_type VARCHAR(100),    -- 서류 종류
  condition_type VARCHAR(50),    -- 조건 타입 (amount, height, floor...)
  operator VARCHAR(10),          -- 비교 연산자 (>=, <=, ==)
  threshold_value DECIMAL,       -- 기준값
  law_reference VARCHAR(200),    -- 법 조항 참조
  effective_from DATE,           -- 시행일
  effective_to DATE,             -- 종료일 (null = 현행)
  priority INT DEFAULT 0,        -- 우선순위
  is_active BOOLEAN DEFAULT true
)
추가 고려: 복합 조건(AND/OR) 처리를 위해 condition_groups 테이블 추가 검토
